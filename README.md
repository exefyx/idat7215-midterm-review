# IDAT 7215 Midterm Review

Bilingual, question-first study site with a glossary, detailed per-question teaching notes, and 15 course and exam PDFs. Answer history and wrong questions are stored locally in the browser on this device.

## Live site

https://exefyx.github.io/idat7215-midterm-review/

## Public materials

The `materials/` directory contains the course slides, exam guidelines, and the three past-midterm PDFs supplied for this study project. The repository and those files are public and downloadable by anyone. Personal homework files and unrelated archives were not included.

## Cross-device progress sync

Cloud sync is not enabled for now. Progress remains on the current computer and browser. The Supabase schema and configuration template are retained for a future setup, but the site does not load them or send progress to a server.

## Local use

Open `index.html` in a modern browser. The generated question bank and teaching notes are included in the page.
