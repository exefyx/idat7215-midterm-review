# IDAT 7215 Midterm Review

A bilingual, question-first study site for the IDAT 7215 midterm. It contains practice questions, exam-style questions, bilingual key terms, and detailed explanations.

## Run locally

Open `index.html` in a modern browser. Answer history is currently stored in that browser's local storage under `idat7215-progress`.

## Deployment and progress sync

This repository is private by request. GitHub Pages on GitHub Free only publishes from public repositories, so this repository cannot be published there on that plan. A separate hosting service that supports private GitHub repositories (for example Cloudflare Pages or Vercel) can publish the static site. The current site stores progress locally; cross-device cloud sync requires a secure authentication and storage backend and has not been enabled yet.

The repository contains the generated study site only. Source course PDFs and past exam PDFs are not included.
## IDAT 7224 study room

Open `idat7224.html` to use the Chapter 01–04 review site. It includes 44 chapter questions, detailed explanations and short-answer rubrics, chapter study cards, a searchable glossary, a timed practice round, and a browser-local wrong-answer list. A link is also available in the IDAT 7215 site's header.

The course PDFs are not included. Progress is stored in the current browser only; it does not sync between devices. This repository remains private by request. GitHub Pages is not enabled for it.
