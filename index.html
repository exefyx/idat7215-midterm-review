Python 与数据工具

list 有序、可重复、可变；set 唯一元素、可变。NumPy ndarray 同质；ndim / shape / size 分别看维度、形状、元素总数。Pandas 的 iloc 按位置，loc 按标签。

AI 与专家系统

BFS 按层展开；DFS 沿分支深入，通常更省内存但不保证最短路径。专家系统由知识库（事实与规则）、推理机和用户界面等组成；前向链从已知事实推结论，后向链从目标反查条件。

机器学习

监督学习使用带标签数据，可做分类与回归；无监督学习从无标签数据中找结构，常见聚类与关联规则。K-means 属于聚类。交叉验证用于评估泛化、帮助控制过拟合；F1 是 precision 与 recall 的调和平均。
